# Ghooomo — Three travel worlds

Static, independent pages:
- `/` — interactive world selector
- `/solo/` — mountain exploration and animated route
- `/couple/` — warm, slow editorial escape
- `/group/` — energetic collage and shared travel planning

Deploy the repository root on Vercel with framework `Other` and no build command. No package installation is needed.

Original logo is preserved. Landscape photographs are locally hosted, optimized WebP files sourced from Unsplash; imagery is illustrative, not a promise of package locations or inventory.

The planner creates and downloads a text travel brief in the browser. It does not send enquiries, store personal information, confirm bookings or accept payments.

Motion can be paused and respects reduced-motion preferences. Mobile navigation, journey filters, keyboard scene switching and native modal dialog are included.
